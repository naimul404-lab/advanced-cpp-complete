# Python Complete Learning Pack

This folder contains a complete beginner-to-advanced Python learning set with examples, mini-projects, and practical exercises.

## Topics covered

- Syntax and variables
- Data types and operators
- Control flow
- Functions and lambdas
- Lists, tuples, sets, dictionaries
- String manipulation
- File I/O
- Exception handling
- Modules and packages
- OOP (classes and inheritance)
- Decorators and generators
- Regular expressions
- Working with JSON and CSV
- Advanced mini-projects
